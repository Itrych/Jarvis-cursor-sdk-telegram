# Безопасность

[English](SECURITY.en.md)

Jarvis — это удалённый пульт к машине, на которой он запущен. Локальный агент Cursor SDK читает файлы проекта и может выполнять команды с правами пользователя демона.

## Как сообщать о проблеме

Не прикладывайте токены, ключи API, содержимое `.env` и дампы сессий.

Напишите владельцу через GitHub. Отдельный контакт для сообщений о безопасности и программа выплаты за уязвимости не объявлены.

## Что уже ограничено

- Бот отвечает только пользователям из `TELEGRAM_ALLOWED_USER_IDS` и `allowed_user_ids`. Пока список пуст, рабочие команды закрыты: `/start` лишь показывает числовой id.
- Секреты читаются из `.env`. В репозиторий попадают только пустые примеры.
- Скачивание файлов разрешено только внутри каталога активного проекта. Путь вида `../` отклоняется.
- В архив не входят служебные каталоги `.git`, `venv`, `node_modules` и аналогичные.

## Что остаётся на операторе

- Токен Jarvis не должен совпадать с токеном другого long poll, включая мост Cursor MCP.
- Ключ Cursor API даёт тратить квоту аккаунта. Храните его только в `.env` на машине демона.
- Демон видит те файлы, которые видит учётная запись Windows или Linux, от которой он запущен. Не запускайте его под администратором без нужды.
- `projects_root` не должен указывать на каталог с чужими секретами, если эти секреты не нужны задаче.
- Потерянный сервер или утёкший `.env`: отзовите токен бота в BotFather и ключ в панели Cursor, затем выпустите новые.
